# Contributing

Thanks for helping maintain this cybersecurity tools reference.

1. Verify the official project or vendor link.
2. Check current licensing and maintenance status before labelling a tool open-source.
3. Add tools only where they are relevant to the service category.
4. Avoid implying a company uses a tool unless there is a reliable public source.
5. Never submit client-sensitive data, secrets, target details, or unredacted assessment evidence.
6. Prefer pull requests with a short explanation and source links.

All testing tools must be used within written authorisation and the agreed scope.
