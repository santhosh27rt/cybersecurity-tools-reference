## 🎯 Purpose

This repository is a **community reference** for learners, security professionals and teams planning authorised security assessments. It groups commonly used tools by service and provides links to official project or vendor pages.

## 🏷️ Open-source vs commercial

- **Open-source:** source code and licence are publicly available; always review the project's licence and maintenance status.
- **Commercial:** paid product or subscription may be required.
- **Mixed:** the category includes both open-source and commercial tools.

A tool appearing here does not mean all features are free or that the tool is endorsed by a vendor or service provider.

## ⚠️ Responsible use

- Test only systems for which you have explicit written authorisation.
- For production, financial, healthcare, industrial, automotive and telecom systems, agree on rules of engagement, test windows, rollback plans and emergency contacts.
- Use sandbox accounts and non-production transactions for financial workflows.
- Never commit client credentials, tokens, personal data, unredacted screenshots or confidential findings.
- Compliance tools support evidence collection; they do not by themselves certify compliance.
